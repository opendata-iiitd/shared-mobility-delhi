# GTFS Flex Shared Mobility Dataset

## Overview
This directory contains a GTFS Flex dataset for shared mobility services around metro stations. The data covers 158 metro stations with available shared mobility options.

## Data Collection Period
- January 2025 to April 2025

## Dataset Contents
The directory includes the following GTFS files:

- `agency.txt`
- `calendar.txt`
- `frequencies.txt`
- `routes.txt`
- `shapes.txt`
- `stop_times.txt`
- `stops.txt`
- `trips.txt`

## Usage
The dataset is compatible with standard GTFS Flex tools and can be used for transit analysis, routing, accessibility studies, and shared mobility research.

## Notes
- All times are in local timezone (Asia/Kolkata).
- Data reflects service availability and shared mobility integration around metro stations during the specified period.
